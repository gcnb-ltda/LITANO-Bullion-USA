# LITANO Bullion USA

Static U.S.-market precious metals storefront designed for GitHub Pages.

## Identity

A distinctly American institutional bullion identity: deep navy, reserve red, warm bullion gold, off-white paper, serif editorial headlines, compact uppercase navigation, market-oriented information hierarchy and restrained premium styling.

## Pages

- `index.html` — Home
- `store.html` — Store with product grid, search and metal/weight filters
- `cart.html` — localStorage cart

## Market conventions

- English (United States)
- USD
- Troy ounce / grams / kilograms
- Gold and silver product taxonomy
- Final price confirmation language for bullion volatility

## GitHub Pages

Publish from the `main` branch root (`/`). The expected project URL is `https://gcnb-ltda.github.io/LITANO-Bullion-USA/` once GitHub Pages is enabled.

## Important

This repository is a static storefront. Live spot pricing, payment processing, ACH/wire automation, account authentication, KYC/AML workflows, tax calculation, inventory reservation, insured shipping integrations and order persistence require external APIs/backend services and appropriate provider approval. Never commit production payment credentials or bank details to this public repository.
